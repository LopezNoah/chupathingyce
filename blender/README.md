# Blender assets

This directory holds the Blender source scene, runtime test asset, textures,
and Forge's custom selector images for the optional platform/Forge work. These
assets are tracked so a checkout can run the platform and Forge visual tests.
Do not add proprietary game maps or third-party art here.

## Forge Grid visual

`forge_grid.blend` is the editable Blender scene and `forge_grid.glb` is the
runtime test export: a 32-by-32-unit plane with an alpha-blended emissive grid.
`forge_grid_color.png` and `forge_grid_emissive.png` are its packed texture sources;
`forge_grid_preview.jpg` is a flat texture preview, not an in-game render.
`forge_gui.png` and `forge_selected_gui.png` are the Forge's unselected and
selected transparent selector images. They are custom art, used by the
interactive Forge launcher and visual regression test, and are not generated by
the grid script.

The build script is `build_forge_grid.py`. Run it from Blender's Scripting
workspace, or with Blender's background Python option. It expects the two PNG
texture sources above in this directory, packs them into the scene, and writes
`forge_grid.blend` and `forge_grid.glb` here. Apply object transforms before
exporting. The GLB is a visual-only fixture; collision is generated by the game.

The runtime GLB reader handles its bounded static-mesh subset, not arbitrary
Blender scenes. See [platform.md](../docs/platform.md) for supported attributes,
asset settings, and limitations. The committed GLB and selector images support
the reader and visual tests; live game tests still require owned CE maps.
